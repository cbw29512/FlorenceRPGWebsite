Tool policy

The Guild should reduce friction, not create another ecosystem lock-in.

A player should be able to learn, roll dice, generate a character, download an adventure, and find a table without being forced into one giant account system.

Accurate labels

Status means something

“Live” means the project itself claims and supports production. “Preview” means exactly that. Development projects stay in the workshop.

Privacy boundary

No silent data sharing

Using a Guild tool should not automatically expose table-matching information, email addresses, or location data to another project.

Useful first

Every tool earns its slot

The public Tool Bench exists for actual table utility—not as a portfolio page for every experiment.

Support the work

Help build better table tools.

Support helps fund the Guild site, beginner resources, original adventures, and continued development of tools that people can actually use.
