Guild project standard

Use the tool. Come back to Light Tower. Keep playing.

The hub is the front door; the projects stay focused. A player or DM should always know what a tool does, whether it is released, and how it fits into the larger Light Tower toolbox.

Clear status

We say what is ready

Live tools are labeled live. Coming Soon means a project is nearing release. Workshop means important capability or certification still remains.

Privacy

Your Guild information stays separate

Opening a tool does not automatically share your table-matching information, email address, or location with another project.

Table first

Every tool earns its place

If a project does not help someone learn, prepare, run, or play a tabletop game, it does not need a spot on the public Tool Bench.

Community-supported · no ads

Help build better table tools.

There are no advertisements or paid placements on the Tool Bench. If a tool saves you time, optional support helps cover hosting and continued development.
